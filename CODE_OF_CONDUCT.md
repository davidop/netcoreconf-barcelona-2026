# Code of Conduct

Our community values respectful, inclusive and technically rigorous collaboration.

We expect contributors to:
- engage with empathy and professionalism;
- critique ideas and implementations, not individuals;
- keep event participation safe and accessible;
- respect privacy, intellectual property and attribution;
- avoid harassment, discrimination, unwanted personal attention or threats.

Maintainers may edit, hide or close abusive issues and contributions, and restrict participation when necessary. Report a Code of Conduct concern privately to the repository maintainers; do not post personally identifying details in a public issue.

This policy applies to project issues, pull requests, code reviews and project-related communications.
